# 3D-bin-packing
This project solved the problem of the 3D bin packing using javaScript/Threejs

Check the live demo: https://aouladlahceneoussama.github.io/3D-bin-packing/

## Sample CSV files

- [`csv-example.csv`](./csv-files/csv-example.csv) is the original demo input.
- [`packrift-ecommerce-cartons.csv`](./csv-files/packrift-ecommerce-cartons.csv) is an ecommerce cartonization sample derived from Packrift's public [cartonization solver fixture pack](https://packrift.github.io/packaging-optimization-benchmark-corpus/cartonization-solver-fixtures.html).
